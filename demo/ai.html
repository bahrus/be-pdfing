be-pdfing + the browser's built-in AI

A handler that sends the extracted text to the browser's built-in language model (Chrome's Prompt API, Gemini Nano), with a JSON schema for the response, compared with the layout-helper handler (main demo). Try demo/home-school-transcript-example.pdf or demo/sample-transcript.pdf.
